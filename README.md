# 無限の猿タイピスト

「猿が無限にタイプライターを叩けば、いつかシェイクスピアを書き上げる」——無限の猿定理をモチーフにした放置型クリッカーゲーム。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要）。右上の「遊び方」でいつでも説明を見られる。

- 「打」ボタンのクリック、またはどのキーでも打鍵。猿のタイプライターからランダムな文字が出て、光っている枠の文字が出たら確定。
- 打った数（打鍵）がお金の代わり。**雇う**タブで猿を雇うと自動で打ってくれる。迷ったら「おすすめ」を買えばよい。
- **強化**タブ：クリックを強くする道具と、猿たちを賢くする研究（当たりやすさ・ヒント短縮・放置効率・同時執筆・ひらめき）。説明には「今 → 次」の数値が出る。
- **ひらめき**：外れが「キー数×2.5回」続くと次の1文字が必ず当たる（研究で回数を減らせる）。
- **コンボ**・**ヒント**・金のバナナ・偶然の単語・迷作・名前つきの猿の成長と進化。

## 全三章

| 章 | 内容 | 目安（ふつうに遊んで） |
|---|---|---|
| 第一章 日本編（全11作） | こんにちは → … → 古池や → 柿食えば → 祇園精舎の → 田子の浦に | 約12〜15分 |
| 第二章 英国編（全11作） | Hello → … → Now is the winter of our discontent → We are such stuff as dreams are made on → To be, or not to be | 約15〜20分 |
| 終章 グローブ座（全8作） | ハムレットの独白を最後の一行「And lose the name of action.」まで → 「The rest is silence.」でエンディング | 約25〜30分 |

章をクリアすると次の舞台へ「渡航」できる。名前つきの猿・実績・作品は引き継ぎ、打鍵・雇った猿・強化はリセット。完成させた作品1つにつき生産 +5% の名声ボーナスが永続でつく。英国編・終章では大文字・句読点・空白もすべてキー。

### 難易度調整の目安

`js/data.js` の次の数値で調整できる。

- `BASE_COST`：全体の物価
- `CHAPTERS[].costMul`：章ごとの物価（英国編 ×6、終章 ×20）
- `inspMaxAt()` / `INSP_MIN`：ひらめきの強さ（序盤は控えめ）
- `fameFor()`：渡航ボーナス

自動プレイでの計測（1秒1クリック・30秒ごとにおすすめを購入）で全編 約50〜65分。

## 構成

- `index.html` — 画面
- `css/style.css` — レトロなタイプライター風スタイル
- `js/data.js` — ミッション・猿・研究・実績などのデータ
- `js/sound.js` — WebAudio 効果音
- `js/game.js` — ゲームロジック（大量の打鍵は幾何分布でまとめて判定）
- `js/fx.js` — 演出（文字の叩きつけ・衝撃波・火花・完成シネマティック）
- `js/icons.js` — Lucide アイコン
- `js/art.js` — 猿とタイプライターの線画（自作 SVG）
- `movie.html` / `css/movie.css` / `js/movie.js` — ティザー映像

セーブは localStorage に自動保存。設定タブから文字列で書き出し／読み込みできます。
