# 無限の猿タイピスト

「猿が無限にタイプライターを叩けば、いつかシェイクスピアを書き上げる」——無限の猿定理をモチーフにした放置型クリッカーゲーム。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要）。

- 「打」ボタンのクリック、またはどのキーを押しても 1 打鍵。ランダムな文字が出て、次に必要な文字が出たら確定します。
- 打鍵数（外れも含む）がそのまま通貨。猿を雇うと自動で打鍵してくれます。
- 後半は「文節ロック」：2〜4 文字連続で当てないと確定しません。
- 研究
  - **教育**：次に必要な文字が出やすくなる
  - **辞書**：この先使わないキーを封印して抽選対象を減らす
  - **執筆チーム**：複数行を別々の猿チームで同時に打つ
  - **留守番**：タブを閉じている間の効率と上限時間を上げる
- 打鍵ログに偶然単語（「さる」「ばなな」など）が現れるとボーナス。
- 金のバナナ 🍌 を拾うとボーナス。ストライキはバナナで説得。

## ミッション（第一章 日本編）

1. こんにちは → 最初の猿が加入
2. さる → 濁点キー追加
3. ありがとう
4. 猿も木から落ちる（2 文字ロック）
5. 春はあけぼの（清少納言『枕草子』）
6. 古池や 蛙飛び込む 水の音（松尾芭蕉／3 文字ロック）
7. 田子の浦に うち出でて見れば 白妙の 富士の高嶺に 雪は降りつつ（山部赤人／4 文字ロック）

第二章「英語編 — シェイクスピア」は準備中。

## 構成

- `index.html` — 画面
- `css/style.css` — レトロなタイプライター風スタイル
- `js/data.js` — ミッション・猿・研究・実績などのデータ
- `js/sound.js` — WebAudio 効果音
- `js/game.js` — ゲームロジック（大量の打鍵は幾何分布でまとめて判定）

セーブは localStorage に自動保存。設定タブから文字列で書き出し／読み込みできます。
