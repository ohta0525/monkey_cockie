# 無限の猿タイピスト

「猿が無限にタイプライターを叩けば、いつかシェイクスピアを書き上げる」——無限の猿定理をモチーフにした放置型クリッカーゲーム。

## 遊び方

`index.html` をブラウザで開くだけ（ビルド不要）。

- 「打」ボタンのクリック、またはどのキーを押しても打鍵。猿のタイプライターからランダムな文字が出て、次に必要な文字が出たら確定。
- **キーボードが成長する**：最初はキー8個（当たり1/8）。ミッションを完成させるたびに新しいキーが増えていく。
- **ひらめきゲージ**：外れが溜まると満タンで次の1文字が確実に確定（天井）。
- **コンボ**：続けて文字を確定させると打鍵の獲得量が増える。
- **ヒント**：待ち時間ごとに次の1文字を猿に教えられる。
- 打鍵数がそのまま通貨。猿を雇うと自動で打鍵し、画面の「猿の部屋」でタイプしている姿が見られる。
- 名前つきの猿は性格（早打ち・詩人肌・寝坊助など）が能力になり、時間やバナナで成長、Lv10・20・35で進化。
- 打鍵ログに偶然単語（「さる」「ばなな」など）が現れるとボーナス。完成直前の打ち間違いは「迷作」として書棚に並ぶ。
- 金のバナナを拾うとボーナス。ストライキはバナナで説得。

## ティザー映像

`movie.html` をブラウザで開いて再生（約30秒・音あり）。F で全画面、M でミュート。映像も音もすべてコード（CSS アニメーション・Canvas・WebAudio）で生成しています。

## 第一章 日本編（全11）

こんにちは → さる → ありがとう → 猫に小判 → 猿も木から落ちる → 春はあけぼの（枕草子） → つれづれなるままに（徒然草） → 古池や（芭蕉） → 柿食えば（子規） → 祇園精舎の（平家物語） → 田子の浦に（山部赤人）

## 第二章 英国編（全9）

日本編をクリアすると「イギリスへ渡る」ことができる（渡航）。名前つきの猿・実績・書棚は引き継ぎ、打鍵・雇った猿・道具・研究はリセット。完成させた作品1つにつき生産 +20% の名声ボーナスが永続でつく。英国ではすべての価格が10倍。

英字のタイプライターは大文字・小文字・句読点・空白もすべてキー。最初はキー7個から始まり、ミッションごとに増える。

Hello → Monkey → To be → What's in a name?（ロミオとジュリエット） → All the world's a stage（お気に召すまま） → Brevity is the soul of wit（ハムレット） → Shall I compare thee to a summer's day?（ソネット18番） → To be, or not to be, that is the question → ハムレットの独白（第3幕第1場）

第三章は準備中。

## 構成

- `index.html` — 画面
- `css/style.css` — レトロなタイプライター風スタイル
- `js/data.js` — ミッション・猿・研究・実績などのデータ
- `js/sound.js` — WebAudio 効果音
- `js/game.js` — ゲームロジック（大量の打鍵は幾何分布でまとめて判定）
- `js/fx.js` — 演出（文字の叩きつけ・衝撃波・火花・完成シネマティック）
- `js/icons.js` — Lucide アイコン
- `js/art.js` — 猿とタイプライターの線画（自作 SVG）
- `movie.html` / `css/movie.css` / `js/movie.js` — ティザー映像

セーブは localStorage に自動保存。設定タブから文字列で書き出し／読み込みできます。
